📖 Setup Guide ▼
1. Install Python packages on your PC: pip install websockets anthropic
2. Start the server on your PC: python server/server.py --token mysecret --cwd C:\Projects
3. Expose it to the internet (free): cloudflared tunnel --url http://localhost:7823 Or: ngrok http 7823
4. Copy the trycloudflare.com URL above, change https:// → wss://, and paste it in Server URL.
Get cloudflared: winget install Cloudflare.cloudflared (Windows) or brew install cloudflare/cloudflare/cloudflared (Mac)
